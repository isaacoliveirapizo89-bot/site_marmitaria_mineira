# 🍛 Cardápio — Marmitas da Cidade

Página web simples criada para apresentar um cardápio de marmitaria de forma organizada e fácil de consultar.

## 📌 Sobre o projeto

O projeto apresenta opções de marmitas, uma breve descrição dos pratos e seus preços. A proposta é praticar a construção de uma página web estática e a organização visual de informações de um pequeno negócio.

Os nomes, descrições e valores exibidos no exemplo são demonstrativos e devem ser confirmados antes de qualquer uso comercial.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do conteúdo e dos itens do cardápio.
- **CSS3:** estilos, cores, espaçamento e apresentação dos cartões.

## 📁 Estrutura do projeto

```text
site_marmitaria_mineira/
├── index.html
├── index.css
└── README.md
```

## ▶️ Como visualizar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

O arquivo HTML utiliza a folha de estilos `index.css`.

## 🎯 Objetivos de aprendizagem

- Praticar a estruturação de conteúdo com HTML.
- Aplicar estilos com CSS.
- Organizar informações em uma página web.
- Desenvolver uma apresentação simples para um cardápio.

## 🔧 Possíveis melhorias

- Adicionar novas opções e categorias ao cardápio.
- Melhorar a experiência em telas menores.
- Incluir informações de contato e pedido, caso o projeto evolua para uso real.
